## OpenConnect v0.21.0: the watch faces (source and build script)

### Install

Download `openconnect-v0.21.0.apk` below and open it. It installs **over v0.20.0 and keeps your data and your keys**
(same signing key). Needs Android 8.0 or newer. Check the download against `openconnect-v0.21.0.apk.sha256`.

### What is new

- **Three real watch faces as Connect IQ source** in the new `watch/` folder: Clean (a ring around the big time),
  Dashboard (four tiles on black) and Retro (a segment bar on indigo). They show what the watch itself knows: Body
  Battery, heart rate, stress, steps and floors.
- **`watch/build.sh`** builds one face for one watch: design, colour, four fields and the device id. Every variant gets
  its own app id, so several can sit on the watch together.
- **The app gives the command.** *Settings, Watch face preview* now shows the command for the face you chose, with a
  *Copy build command* button.
- **Floors replace Sleep as a field**, because Garmin's API gives a watch face no sleep length. The preview of v0.20.0
  had a Sleep field; a saved choice that has it falls back to the default fields.
- Guide: `docs/WATCH_FACES.md`.

### What you have to do once

The watch faces are **not built for you** in this release. Garmin's device files for the fenix 8 can only be downloaded
with a Garmin login (SDK Manager), so the build environment cannot make the `.prg`. On your computer:

1. Install the Connect IQ SDK and download your watch in Garmin's SDK Manager.
2. Run `watch/build.sh --make-key --device fenix847mm --design clean --color blue` (or paste the command from the app).
3. Copy the `.prg` to the watch with the app (*Settings, Watch face*) or into `GARMIN/Apps`, then choose it on the watch.

### Not verified

- The Monkey C has **not been compiled or run**. The functions and constants it uses were checked against the Connect IQ
  9.3.0 API list, nothing more. If `monkeyc` complains, send the message.
- The install of a `.prg` over USB on a real fenix 8, as in v0.18.0.

### What changed in the code

- `watch/` (new): `manifest.xml` (template), `monkey.jungle`, `source/` (`OpenConnectFaceApp.mc`, `FaceView.mc`,
  `Faces.mc`, `Data.mc`), `resources/` (launcher icon) and `build.sh`.
- `build.sh` checks every choice, writes `gen/` and starts `monkeyc`. `--dry-run` stops after writing the files.
- App: `WatchField.FLOORS` replaces `SLEEP`; `WatchFaceData.floors`; the build command and *Copy build command* button
  in the preview card.
- Tests: `tests/test_watch_build.py` (Python, 9 tests) runs `build.sh --dry-run` and checks the generated files and every
  refusal. `WatchPreviewTest` now covers the floors field and the shown command.
