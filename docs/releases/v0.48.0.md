## OpenConnect v0.48.0: update from inside the app

The Android app can now update itself from this project's GitHub releases, with a checksum check before Android is
asked to install anything.

### Install

Download `openconnect-v0.48.0.apk` below and open it. It installs **over v0.47.0 and keeps your data and your keys**
(same signing key). Needs Android 8.0 or newer. Check the download against `openconnect-v0.48.0.apk.sha256`.
From this release on, **Settings → Updates** can do the same for you.

### What is new

- **In-app updater** (*Settings → Updates*). The app asks GitHub for the latest release, compares the tag with its own
  version and shows the available version. *Download and verify* fetches the signed APK, checks its SHA-256 against
  the `.sha256` asset published with the release, and keeps the verified file in the app's cache. *Install update*
  hands it to Android's installer through a content provider. On Android 8 and newer the first install needs the
  system switch "install unknown apps" for OpenConnect; the app opens that setting for you. A failed download or a
  checksum mismatch never reaches the installer.
- The download is capped at 60 MB, HTTPS only, and the updater says clearly when GitHub cannot be reached or a
  release has no APK. A cached, already verified APK is reused.
- English and Dutch strings; a card on Settings with the current version and buttons for check, download and install.

### Not verified

- **No real phone and no real GitHub release were used.** The updater was exercised on the JVM against a fake GitHub
  answering release JSON, APK bytes and a checksum. Android's install flow, the "install unknown apps" setting and
  whether a signed APK from a later release installs over this one can only be checked on a device.
- The app cannot update itself on a phone that blocks installs from outside a store; the system setting must allow it.

### What changed in the code

- `core/updates/Release.kt` (new): release parsing, version comparison, SHA-256 check.
- `core/updates/UpdateHttp.kt` (new): HTTPS GET with a size cap and download progress.
- `updates/UpdateController.kt` (new): check, download, verify and cache state.
- `ui/UpdateCard.kt` (new) and `SettingsScreen.kt`: the Settings card.
- `AndroidManifest.xml`: `REQUEST_INSTALL_PACKAGES` and a FileProvider for `cacheDir/updates`;
  `res/xml/file_paths.xml` (new).
- `AppContainer`/`OpenConnectApp`: injectable update network and cache directory for tests.
- Tests: release parsing and checksum (core), the controller and the Settings card with a fake GitHub (app).
- Version 0.48.0, versionCode 48.
