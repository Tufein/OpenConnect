## OpenConnect v0.22.0: your watch model and one face per colour

### Install

Download `openconnect-v0.22.0.apk` below and open it. It installs **over v0.21.0 and keeps your data and your keys**
(same signing key). Needs Android 8.0 or newer. Check the download against `openconnect-v0.22.0.apk.sha256`.

### What is new

- **Pick your watch.** *Settings, Watch face preview, Watch*: fenix 8 43 mm, 47 mm, Pro 47 mm, Solar 47 mm or Solar 51
  mm. The choice goes into the build command, because a face is built for one model.
- **The app names the file.** Under the preview it says which file to pick when you install, for example
  `openconnect-retro-FF5FA2-fenix847mm.prg`. The build script gives the file the same name.
- **One face per colour in one go.** `watch/build.sh --all-colors` builds mint, blue, amber, pink and green for the
  design you give. Every colour has its own app id, so you can keep several on the watch and choose between them on
  the watch itself. This is how colour is "chosen without Garmin's app": the choice is in the file you install.

### Not verified

- The Monkey C of v0.21.0 is still **not compiled**: the device files need your Garmin login (see `docs/WATCH_FACES.md`).
- The Solar models have a different screen than the AMOLED ones; the preview is drawn for the AMOLED.

### What changed in the code

- `watch/build.sh`: rewritten into small functions; `--all-colors`; the dry run prints the file name for each colour.
- App: `WatchDevice` (the five models), `WatchFaceConfig.device`, `deviceValue` and `fileName()`; `SettingsStore.watchDevice`;
  `AppViewModel.setWatchFace` now takes the whole `WatchFaceConfig`. Settings has the Watch chips and the file name line.
- Tests: the Python tests check `--all-colors` and that its file names equal the ones the app builds
  (`WatchFaceConfig.fileName`); `WatchPreviewTest` covers the watch choice and the file name.
