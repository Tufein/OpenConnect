## OpenConnect v0.6.0: sync your Garmin watch over Bluetooth

The app can now **pair with a Garmin watch and download its files over Bluetooth**, with no cable, no Garmin account
and no Garmin Connect app. Written for the fenix 8. **Not yet tried on a real watch**, so please treat it as a first test.

### Install

Download `openconnect-v0.6.0.apk` below and open it. It installs **over v0.5.0 and keeps your data and your keys**
(same signing key). Needs Android 8.0 or newer. Check the download against `openconnect-v0.6.0.apk.sha256`.

### What is new

- **Bluetooth sync for Garmin watches.** *Watch, Sync a Garmin watch over Bluetooth*: find the watch, pair, and the app
  downloads activities, monitoring (steps, heart rate, stress, Body Battery), sleep (with HRV) and health snapshots. It
  shows each step (pairing, connecting, handshake), remembers the watch for next time, and skips files it already read.
- **New licence: AGPL-3.0-or-later.** The Bluetooth protocol is ported from Gadgetbridge, which is AGPL-3.0. Releases up
  to v0.5.0 stay MIT. See `NOTICE`.

### What changed in the code

- New `core/watch/ble/` package (pure Kotlin): CRC-16 and COBS framing, the multi-link service with MLR
  (acknowledgements, resends, a 32-packet window), GFDI messages, the session that does the handshake and the file
  transfer, and a `WatchSource` adapter so the existing FIT import is reused.
- New `AndroidGarminBleLink`: scan, bond, GATT connect, MTU 515, notifications, a serialized write queue.
- `WatchController` gained find, sync, forget and a remembered watch; the Watch screen got a new card. English and Dutch.
- Version 0.6.0, versionCode 6.

### How it was checked

- 262 core tests, including Gadgetbridge's real byte vectors from an Instinct 2S, and a separately written simulated
  watch that drops, damages and delays packets.
- App tests for the controller and the Watch screen (Robolectric), Python tests, lint and the release build.

### Known limits

- Not tested on a real watch yet. Garmin Connect on the same phone will probably stop syncing while OpenConnect is
  paired. Files are not archived on the watch. No background Bluetooth sync. See `docs/BLUETOOTH.md`.
