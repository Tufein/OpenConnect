## OpenConnect v0.3.0: read your Garmin watch directly

The Android app can now read a Garmin watch **without a server, without a Garmin Connect account and without
Garmin Connect on the phone**. Two routes are built; a third was ruled out on purpose.

### Install

Download `openconnect-v0.3.0.apk` below and open it. It installs **over v0.2.0 and keeps your data** (same signing
key, the database upgrades itself). Needs Android 8.0 or newer. Check the download against
`openconnect-v0.3.0.apk.sha256`.

### What is new

- **Watch screen, USB cable.** Plug the watch into the phone (the phone needs USB host / OTG support), allow access
  and press *Sync*. The app reads the FIT files in the watch's `GARMIN` folder:
  - activities (imported like any FIT file, marked as coming from the watch),
  - steps, distance, calories, floors climbed and intensity minutes per day,
  - heart rate through the day and resting heart rate,
  - stress, Body Battery, blood oxygen (SpO2), respiration,
  - HRV and sleep stages with the sleep score.
  A file is only read once, a failed file is retried next time, and syncing the same data twice never doubles anything.
- **Watch screen, Bluetooth.** Live heart rate from any device that uses the standard Bluetooth heart rate profile
  (a chest strap, or a Garmin watch with heart rate broadcast switched on), with beat-to-beat HRV (RMSSD). A live
  session can be saved as an activity.
- **Health screen** gets HRV, blood oxygen and respiration cards, and the Home screen a card that opens the Watch screen.
- The app is also offered when a Garmin watch is plugged in.
- New permissions: Bluetooth scan (flagged as not used for location) and connect, and USB access when you plug the watch
  in. On Android 11 and older Android itself ties Bluetooth scanning to the location permission. USB and Bluetooth are
  optional, the app also installs on phones without them.

### What was looked at and not built

- **Garmin Health SDK**: reads a watch over Bluetooth, but only for approved enterprise partners (application, licence,
  minimum order). Not available to this project.
- **Gadgetbridge's way** (Garmin's reverse engineered Bluetooth protocol): Gadgetbridge is AGPL-3.0, which cannot be copied
  into this MIT project, and rewriting it without a watch to test on would be guesswork.
- **Health Connect**: needs the Garmin Connect app and account to fill it, has no Body Battery or stress, and is not
  real time. A possible extra source later.

Details and sources: [docs/WATCH.md](https://github.com/Tufein/OpenConnect/blob/main/docs/WATCH.md).

### How it was built

Test first, in the pure Kotlin `core` module: a generic FIT reader (field arrays, invalid markers, the 16-bit timestamps
watches use), a reader for monitoring, sleep and all-day-health files, daily aggregation, the sync, the folder logic for
USB (behind an interface, so it runs without USB), and the Bluetooth heart rate parser. The test files were written by
**Garmin's own FIT encoder**, so the tests read files our code did not make (the generator is committed; Garmin's SDK is
not shipped). The core now has 109 tests and the app 36, including a UI test that drives the Watch screen with a fake USB
link and a fake Bluetooth sensor and a test of the database upgrade from v0.2.0.

### Known limitations: please read

- **Nothing has been tried on a real watch yet.** The USB permission flow, Android's `MtpDevice`, the Bluetooth scan and
  connection, and above all whether *real* Garmin files match what was assumed from Garmin's FIT specification have only
  been checked against synthetic files. Watch models differ in what they store. If something is missing or wrong, the
  Watch screen's sync report shows how many files failed and why; please report it together with the watch model.
- **Garmin Connect can delete files from the watch** once it has uploaded them (Monitor, Sleep, HRV). If you use both,
  sync with OpenConnect first.
- Garmin does not officially support a phone as USB host, and some watches only offer a mass-storage or "Garmin" mode that
  Android cannot open.
- Not read yet: the `Metrics` folder (VO2 max, training status), settings, workouts and courses. Achievements are still
  not in the app.
- Garmin account sync (Personal API) is still not built; it needs Garmin's approval and a key.
