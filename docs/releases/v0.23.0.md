## OpenConnect v0.23.0: glance and widget for your watch

### Install

Download `openconnect-v0.23.0.apk` below and open it. It installs **over v0.22.0 and keeps your data and your keys**
(same signing key). Needs Android 8.0 or newer. Check the download against `openconnect-v0.23.0.apk.sha256`.

### What is new

- **A glance and a widget for the fenix 8.** *Settings, Watch face preview, Widget and glance* names the file and has a
  button that copies the build command. The glance shows three of your fields on one line in the glance list; opening
  it gives a widget screen with a ring, four rows and a line of your Body Battery over the last 12 hours.
- **Same colour and fields as your face**, but one look; the file is `openconnect-widget-<COLOUR>-<model>.prg`.

### Not possible, and why

- **No sleep screen.** The roadmap listed one, but a Connect IQ app cannot read how long you slept: Garmin offers no
  sleep-duration API to watch apps. The widget shows Body Battery, heart rate, stress, steps and floors instead.

### Not verified

- The Monkey C is still **not compiled** (the device files need your Garmin login, see `docs/WATCH_FACES.md`). Build it
  once on your computer with `watch/build.sh --type widget`; if `monkeyc` reports an error, send it and it is fixed.
- Whether the glance fits in the glance memory of the watch is unknown until it runs on the watch.

### What changed in the code

- `watch/manifest.xml` is now a template for both app types (`__ENTRY__`, `__TYPE__`); `watch/build.sh` got `--type`.
- New `watch/source/OpenConnectWidgetApp.mc`, `WidgetView.mc`, `OpenConnectGlance.mc`; `Faces.widget()` draws the
  widget; `Data.bodyBatteryHistory()` reads the last 12 hours; `Config` and `Data` got the `(:glance)` annotation.
- App: `WatchFaceConfig.widgetCommand()` and `widgetFileName()`, a card section with a copy button, strings (en/nl).
- Tests: a dry-run test for the widget manifest, file name and annotations; the app test checks the command and name.
